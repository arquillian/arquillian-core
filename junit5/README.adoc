= Arquillian JUnit Jupiter Integration

This module provides Arquillian integration for JUnit Jupiter.

== JUnit Compatibility

This module supports the *JUnit Jupiter* platform.

[IMPORTANT]
====
Despite the `junit5` naming convention, this module provides first-class support for both **JUnit 5** and **JUnit 6**.
The module name reflects the integration origin rather than a version limitation.
====

== JDK Compatibility

The minimum JDK requirement depends on the version of JUnit used:

* **Using JUnit 5.x** requires **Java SE 8** or later.
* **Using JUnit 6.x** requires **Java SE 17** or later.

== Usage

[source,xml]
----
<dependency>
    <groupId>org.jboss.arquillian.junit5</groupId>
    <artifactId>arquillian-junit5-container</artifactId>
    <version>${org.arquillian.version}</version>
</dependency>
----

== Configuration

=== `arquillian.junit.jupiter.manager.scope`

JUnit configuration parameter. Accepts `suite` (the default) or `class`, and
decides whether one Arquillian `Manager` serves the whole run or each test
class gets its own. Class scope is what makes parallel test class execution
possible.

The feature is experimental and only works with some container types. See
https://arquillian.org/arquillian-core/#_parallel_test_class_execution[Parallel Test Class Execution]
in the Arquillian Core guide for the full description, including how to turn
on Jupiter's parallel execution alongside it.
